# 只暴露决策状态

游戏内 MCP 服务器负责处理 Balatro 的动画和事件队列转换，绝不将其作为客户端可见状态暴露。它会自动推进只有强制确认、没有实际选择的界面，例如 Blind 结束后的兑现界面。状态查询和语义动作只有在到达决策状态后才成功；动作后的新状态必须在连续观察中保持一致，服务器才将其视为稳定。若有界等待超时，则返回不含状态快照的 `DECISION_TIMEOUT`，而不是泄露中间状态或过期状态。

显式 `get_game_state` 返回完整 State Snapshot；语义动作返回同一 Decision State 的精简投影。两者共享 `state_hash` 和 Target ID，精简投影必须足以直接提交下一项合法动作。这样既保留无状态恢复能力，也避免自主游玩循环在每步重复接收固定环境信息和可推导显示字段。
