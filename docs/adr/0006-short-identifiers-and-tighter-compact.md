# 缩短标识符并收紧精简投影

State Hash 与 Target ID 曾使用带前缀的长十六进制串，完整快照、动作响应和带状态的错误还会重复抄写目标列表与显示字段。协议仍可破，因此改为：State Hash 仍是对局标识、决策序列与状态快照的内容指纹，但只输出 8 位十六进制、去掉 `sha256:`；Target ID 原样暴露内部目标引用（如 `card:12`），同一对局里字符串可以复用，离开配套 State Hash 即无效；`get_game_state` 仍返回完整 State Snapshot，但与精简投影一样用 `target_sources` 代替覆盖全集的目标列表；语义动作与带状态的错误都返回精简投影，去掉 `name` / `description` 及可由 `key` 推导的字段。MCP `content.text` 短摘要已被 ADR 0008 取代。

## Considered Options

- **只用决策序号当过期令牌**：也能拒绝「游戏里先点了一步」，但 fair / omniscient 不再分钥，同序号下快照内容变化也不拒。否决。
- **截断 Target 哈希，或每步把序号掺进 ID**：更不透明，或强迫每步换号。已有短引用足够区分实例。否决。
- **连 `get_game_state` 也改成精简投影**：省得更多，但丢掉百科式恢复入口。否决。
- **错误不附快照**：再省一轮上下文，但失败后必须再查一次才能合法出手。否决。
